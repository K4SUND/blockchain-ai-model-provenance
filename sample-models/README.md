# Demonstration model artifacts

Do not commit a model file until the team has checked its size, source, and licence.

The demonstration eventually needs:

1. a small existing AI model artifact, preferably ONNX or TensorFlow Lite;
2. an untouched original copy;
3. a deliberately modified copy that produces a different SHA-256 hash; and
4. a completed provenance manifest based on `provenance-manifest.example.json`.

Record the original download page, creator, licence, file size, and expected SHA-256 hash here before adding or distributing the model.

The team must not claim to have trained an externally sourced model. It is only an artifact for demonstrating integrity and provenance verification.
