# Three-minute demonstration script

This file is intentionally a draft. Task `DOC-03` finalizes it after the application works end to end.

## Preparation

- Start the local blockchain and deploy the contract.
- Start the frontend.
- Prepare publisher and verifier wallets.
- Keep the original and modified demo model files ready.
- Register the model before the timed presentation if transaction time is uncertain.

## Planned flow

1. Explain the AI-model tampering problem.
2. Show the model's registered publisher, version, hashes, and status.
3. Verify the original file and show `Verified`.
4. Verify the modified copy and show `Hash mismatch`.
5. Show or explain revocation and immutable history.
6. State the boundary: ModelGuard proves artifact integrity and registered provenance, not model quality.
