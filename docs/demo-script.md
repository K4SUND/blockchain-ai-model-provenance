# Three-minute demonstration script

The final team script, timings, slide changes, recording instructions, and rehearsal checklist are maintained in [`presentation/README.md`](presentation/README.md).

The required demonstration sequence is:

1. register `DemoClassifier` version `1.0.0` using the original model;
2. verify the original model and show **Verified**;
3. verify the modified model and show **Hash mismatch**;
4. revoke the registered version with a public reason; and
5. verify the original model again and show **Revoked**.

Use a full-screen recording of the real application rather than the small static screenshots in the slide deck. The complete video should finish between 2:55 and 2:58, leaving a small margin below the three-minute limit.
